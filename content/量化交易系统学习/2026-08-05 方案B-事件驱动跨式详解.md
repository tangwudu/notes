# 事件驱动跨式详解（方案B）

> [!abstract] 一句话总结
> **在 CPI / FOMC / 财报等确定性事件前，买入 ATM 跨式（call + put），赌波动率爆发，事件后立即离场。** 与方案A互补：A 平时跑趋势，B 事件日吃波动，两者合计日亏损熔断仍为总资金 2.5%。

## 为什么适合小资金 + 期权

| 优势 | 说明 |
|---|---|
| 不用盯盘 | 一天 0–2 笔，管理极简 |
| 入场时机被"事件"自动解决 | 趋势跟踪最难的部分（何时进场）由日历确定 |
| 风险有上限 | 买跨式最大损失 = 权利金，没有卖方的 gamma 爆仓风险 |
| 与方案A互补 | 方案A在事件日会被事件过滤器拦下（不开新仓），B 正好接手 |

## 策略逻辑

```
事件前 60–120 分钟:
  买入 ATM call + ATM put (同 expiry, 3–7 DTE)
  总权利金 ≤ 资金 × 2%   ← 硬上限 (默认 $20k 账户 → $400)

事件时刻: 持有, 吃 IV 放大 + 方向性波动

退出 (先到先出):
  a) 事件后 60–90 分钟 (IV 释放完毕)
  b) 总权利金回撤 ≥ 50% (止损)
  c) 当日收盘强制平仓
```

## 事件来源（两层）

| 事件 | 时间 (ET) | 数据源 | 维护方式 |
|---|---|---|---|
| CPI / PPI / FOMC | 08:30 / 14:00 | `config.json` 的 `event_filter.macro_events` | 手动（如 `"2026-08-06 08:30:CPI"`） |
| 财报 | 盘前/盘后 | yfinance `Ticker.calendar` | 自动 |

```bash
python3 -m intraday.plan_b --days 7          # 扫描未来7天事件 (默认 scan 模式)
python3 -m intraday.plan_b --open --paper    # 模拟开仓 (需在事件前窗口内)
python3 -m intraday.plan_b --open --live     # 实盘开仓 (需确认)
python3 -m intraday.plan_b --close           # 事件后平仓
```

## 成本与盈亏结构（实测链路）

以 AAPL 3 天期 ATM 跨式为例（yfinance 实测）：

```
ATM 跨式成本 = C$4.70 + P$3.55 = $8.25 (单组)
预算检查: $8.25 ≤ $400 (资金×2%) ✅
```

> [!warning] 关键风险: IV crush 陷阱
> 事件结果**符合预期** → IV 暴跌，即使方向没走错也可能双杀。
> 所以必须有止损 (b) 和时间退出 (a/c)——买跨式不是"买彩票放着"，是"进赌场带止损"。

## 为什么它的胜率分布能成立

- 胜率约 40–50%，盈亏比 1.5–3.0（事件波幅大时 call/put 一边能到 2–3 倍）
- 靠少数大赚覆盖多数小亏——与趋势跟踪同构的"大赢小亏"结构
- 事件（CPI 0.5%-1% 的日内波动、FOMC 大阴线/大阳线）是**确定性高波动来源**，这是方案B的 edge 假设

## 实现与已知限制

| 模块 | 状态 |
|---|---|
| 事件扫描 `scan_events` | ✅ 宏观(config) + 财报(yfinance) |
| 跨式成本估算 `straddle_cost` | ✅ yfinance 期权链（bid/ask 为 0 时用 lastPrice 兜底） |
| 开仓 `open_positions` | ✅ 预算风控 + paper/live |
| 平仓 `close_positions` | ⚠️ 框架演示，实盘需接富途实时期权报价 + IV 监控 |
| 期权代码 | ✅ 复用 `build_option_code`（US.SYMYYMMDDCPxxxxxx） |

> [!note] 与主系统的关系
> 主系统（日频）的事件日历 `MACRO_EVENTS` 在 `.env` 维护；intraday 的事件在 `config.json` 维护。两边格式统一为 `日期[:时刻]:事件名`，建议同步维护，避免"主系统知道有 CPI、日内引擎不知道"。

## 与方案A的对比

| | 方案A (趋势) | 方案B (事件) |
|---|---|---|
| 频率 | 每日 1–3 笔 | 每月 5–10 笔 |
| 盯盘 | 需要（可自动化） | 不需要 |
| 胜率 | 40–55% | 40–50% |
| 盈亏比 | 1.5–2.5 | 1.5–3.0 |
| 期权占比 | 低（正股为主） | 100% |
| 主要风险 | 假突破/趋势反转 | IV crush |
| 建议资金 | 60–70% | 30–40% |
