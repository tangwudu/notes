# 日内交易策略详解（ORB + VWAP + EMA 趋势跟踪）

> [!abstract] 一句话总结
> **顺势而为的日内趋势跟踪**：用 EMA 定大势方向 → 用开盘区间突破抓入场时机 → 用 VWAP 做方向纪律 → 用 ATR 止损 + 时间退出控制风险。1 分钟 bar 驱动，持有 30 分钟到数小时，收盘前全部离场，绝不过夜。

## 策略画像

| 维度 | 取值 |
|---|---|
| 标的 | SPY / QQQ（正股，流动性最好的美股 ETF） |
| 工具 | 正股（默认）；期权模式仅原型（delta 近似，未实盘） |
| 时间尺度 | 1 分钟 bar（原生 K_1M，非 15 秒） |
| 持有周期 | 30 分钟 – 数小时 |
| 交易时段 | 9:30–16:00 ET（RTH 常规时段） |
| 频率 | 每日 1–3 笔 |
| 期望形态 | 低胜率（40–55%）+ 高盈亏比（1.5–2.5:1） |

## 一、信号链（三层过滤，缺一不可）

```
┌─ 第1层 方向过滤: EMA(20) vs EMA(50) @5分钟bar
│       快线在上 → 只做多    快线在下 → 只做空
│       两线缠绕(±0.1%) → 不开仓
│       [逻辑: 先定大势, 顺势而为, 过滤逆势假突破]
│
├─ 第2层 入场触发: ORB 开盘区间突破 @1分钟bar
│       开盘前15分钟(9:30-9:45)的高低点 = [ORB_H, ORB_L]
│       价格突破上沿(且前一根在区间内) → LONG 信号
│       价格跌破下沿 → SHORT 信号
│       [逻辑: 开盘一小时是信息最密集、方向最明确的时段,
│              区间突破 = 当天多空双方决出胜负的第一信号]
│
└─ 第3层 VWAP 纪律: 入场前再验一道
         LONG 要求 close > VWAP;  SHORT 要求 close < VWAP
         [逻辑: VWAP 是机构资金的当日基准价, 价格在 VWAP 哪一侧
                就是当日资金站在哪一边; 逆 VWAP 的突破大概率是假突破]
```

> [!note] 三层的分工
> EMA 管"方向"（小时级），VWAP 管"当日多空"（日级），ORB 管"时机"（分钟级）——三个不同时间尺度、不同逻辑的信号互相验证，任何一个不确认都不进场。单一突破信号假信号率太高，这是多层过滤的原因。

## 二、退出机制（先到先出，三个出口）

| 出口 | 规则 | 逻辑 |
|---|---|---|
| **ATR 止损** | 入场价 ∓ 2×ATR(14)（1分钟bar） | 波动率自适应：市场剧烈时止损宽、平稳时止损紧。不设固定百分比，因为"2%止损"在波动大时是噪音自残 |
| **VWAP 反向** | 多头跌破 VWAP / 空头站上 VWAP → 退出 | 趋势失位的第一信号：价格回到当日均值，说明动能已散 |
| **时间退出** | 收盘前 30 分钟强平；15:30 后不开新仓 | 日内策略的生命线：不过夜 = 没有隔夜跳空风险、没有 theta 拖累 |

## 三、仓位管理（"风险先定，仓位后算"）

```
风险预算 = 资金 × 0.8%          ($20k → 每笔最多亏 $160)
正股:  股数 = min( 风险预算/止损距离,  资金×1.0/价格 )
期权:  张数 = min( 风险预算/(止损距离×100), 5张 )
```

止损距离（2×ATR）定了，仓位就反推出来——**每笔亏损上限在入场前就是确定的**。名义值上限（≤1 倍资金）防止小账户高杠杆。

## 四、风控体系（全部确定性代码，无 LLM 参与）

- **日亏损熔断**：当日已实现亏损 ≥ 2.5% → 全平 + 当天禁开 + Telegram 通知
- **事件过滤器**：财报日 / 宏观事件（CPI/FOMC）前 2 小时 → 不开新仓
- **kill switch**：手动文件一键全平+停
- **滑点审计**：每笔记录"模型价 vs 券商成交价"，回测成本用实测校准
- **执行纪律**：信号 bar 收盘后下一根开盘成交（防 look-ahead），买用 ask 市价化限价单

## 五、核心逻辑（为什么这套设计能成立）

1. **趋势跟踪的赚钱数学**：不预测方向，只跟随已发生的突破。胜率低（40–55%）但盈亏比高（让利润奔跑、砍亏损快）——靠"大赢小亏"活，靠截断亏损活下来。

2. **为什么 1 分钟而不是 15 秒**：15 秒 bar 的信号（$0.01–0.05）和交易成本（$0.04–0.10）同数量级——期望值为负。1–5 分钟是"趋势能被识别、成本能被覆盖"的最低可行尺度。**这是整个方案从 15 秒改成 1 分钟的根本原因。**

3. **为什么 SPY/QQQ 而不是个股期权**：流动性和成本是趋势跟踪的生命线。SPY 价差 0.01（实测），滑点 1 个基点以内——盈亏比才能成立。冷门期权价差 5–20% 会把任何 edge 吃光。

4. **为什么只用 RTH（9:30–16:00）**：ORB 和 VWAP 本身就是 RTH 概念（盘前盘后的 VWAP 完全失真）；盘前盘后的价格在开盘大量回补跳空；夜盘没有富途数据和做市商。**这套策略的时间战场就是开盘到收盘的 6.5 小时。**

5. **为什么强制时间退出**：日内策略的时间价值——没有隔夜跳空风险、没有期权 theta 拖累、每天从零开始（日 P&L 清零、ORB 重新计算），风险可计量、可复盘。

## 六、诚实声明（务必阅读）

> [!warning] 当前状态
> 1. **样本极少**：模拟盘刚开始积累（每日 2–4 笔）。回测仅 3 个真实交易日、4 笔交易、100% 胜率——**这是运气，不是 edge 的证据**。
> 2. **判断策略好坏的唯一标准**：模拟盘积累 30+ 笔真实成交 → 看胜率/盈亏比/成本占比 → 用实测滑点校准回测 → 校准后仍有正期望才考虑碰真钱。
> 3. **已知弱点**：震荡市会连续小亏（胜率 40% 意味着 10 笔里 6 笔是亏的）；开盘假突破频繁；它赚的是"趋势日"的钱，趋势日少的时候整体会磨。
