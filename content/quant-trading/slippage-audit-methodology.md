# 滑点审计方法论（回测成本校准闭环）

> [!abstract] 一句话总结
> **回测用"固定滑点"是幻觉**。正确做法：模拟盘每笔成交记录"模型假设价 vs 券商实际成交价"，积累 30+ 笔后把**实测滑点分布**注入回测成本模型——回测曲线才可信。

## 问题：为什么固定滑点不靠谱

回测常见做法是拍一个 `slippage_pct = 0.02%` 之类的固定值。但它有两个致命盲区：

1. **流动性随时间变化**：开盘/收盘滑点大，盘中滑点小；新闻时刻滑点暴涨
2. **固定值一旦拍低**，回测的"好看曲线"就是幻觉——实盘会被真实滑点吃穿

实测案例（模拟盘数据）：

```
▶ 固定滑点 (config)    总P&L: $-5666 | 成本 $2110
▶ 实测滑点 (0.042%)    总P&L: $-6316 | 成本 $2760
  滑点校准对总P&L影响: $-649   ← 固定值低估了真实成本
```

> [!warning] 教训
> 固定值 vs 实测值差 $649——**在判断策略盈亏之前，先校准成本，否则一切结论都是空中楼阁。**

## 闭环架构

```
回测 (固定滑点) ──► 模拟盘跑 (富途 SIMULATE 真实成交)
      ▲                      │
      │                每次开/平仓自动记录:
      │                model_price vs fill_price
      │                      │
      └── 实测滑点统计 ←── intraday.db/slippage 表
       (--apply-slippage 替换固定值, 输出对比)
```

## 记录什么（slippage 表结构）

| 字段 | 含义 |
|---|---|
| model_price | 模型假设成交价（信号后下一根 bar 开盘价，与回测口径一致） |
| fill_price | 券商实际成交价（`dealt_avg_price`） |
| spread | 成交时点的盘口价差 |
| slippage_pct | (fill − model) / model，正 = 不利滑点（买高/卖低） |
| mode | paper / live / offline |

**为什么模型价用"下一根 bar 开盘价"**：回测和实盘共用同一成交假设，滑点审计测的就是"假设 vs 现实"的偏差——这是防 look-ahead 纪律的延伸。

## 怎么用

```bash
# 模拟盘跑 1-N 个交易日 (自动记录滑点)
python3 -m intraday.engine --mode paper

# 积累 20-30 笔成交后:
python3 -m intraday.backtest --slippage-report          # 看实测滑点分布
python3 -m intraday.backtest --apply-slippage --days 5  # 实测值重跑回测+对比
```

统计口径（`db.slippage_stats`）：
- 总体：n / mean / median / p90 / worst（bps）
- 分方向：open 平均 / close 平均（开仓滑点和平仓滑点往往不同）

## 实测基线（SPY/QQQ，高流动性标的）

```
SPY 盘中价差 ~0.01 | QQQ ~0.04
开仓实测滑点: QQQ -0.0098% (成交优于模型) / SPY +0.0059% (成交劣于模型)
平均: ~0 bps 量级
```

> [!note] 流动性决定滑点
> 正股 ETF 的滑点在 bps 级；**期权可能到 1-3%，冷门期权 5-20%**。做期权策略时滑点审计比正股重要一个数量级——这是"先正股跑通再上期权"的量化理由。

## 纪律要求

1. **样本 ≥ 30 笔**才可信（滑点是分布不是均值，p90 比 mean 更能反映极端）
2. **offline 模式滑点恒为 0**（本地模拟成交），只有 paper/live 的实测才有效
3. **异常滑点告警**：超过 0.5% 触发日志警告（可能流动性异常/大新闻）
4. **分模式统计**：paper 和 live 的滑点分布不同（live 有真实盘口深度），切换模式后重新校准
5. **校准是前提不是终点**：校准后回测仍为正期望，才值得讨论调参；否则先解决成本问题

## 常见误区

| 误区 | 正确做法 |
|---|---|
| 滑点用固定的 0.02% | 用实测分布（mean + p90） |
| 只看成交均价不看分布 | 同时看 open/close 分开的分布 |
| 回测和实盘成交口径不一致 | 统一"下一 bar 开盘成交" |
| 用 model 价格算 P&L | 实盘 P&L 一律用券商实际成交价 |
